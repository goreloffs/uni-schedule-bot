# uni-schedule-bot

Парсер расписания занятий университета + Telegram-бот для быстрого доступа к парам.

## Что делает

- Логинится на сайте университета и парсит расписание моей группы
- Складывает данные в PostgreSQL
- Обновляет расписание по расписанию (cron)
- Отдаёт расписание через Telegram-бота: `/today`, `/tomorrow`, `/week`, `/month`

## Стек

- **Backend:** Python 3.11+, httpx, BeautifulSoup, SQLAlchemy, Alembic
- **БД:** PostgreSQL, Redis (кэш)
- **Бот:** aiogram
- **Инфраструктура:** Docker, docker-compose, Nginx, GitHub Actions
- **Планируется:** k3s, Ansible, Prometheus + Grafana, Vault/SOPS
